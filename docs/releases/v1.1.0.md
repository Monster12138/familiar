# Familiar v1.1.0

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- **首次启动引导页（Onboard）**：首次打开应用时展示欢迎介绍（桌宠随 Agent 活动变化 / 注入 Hooks 同步状态 / 数据本机处理），点「下一步」在**同一窗口内**切换到 Hooks 管理，「完成」或「跳过」结束引导。是否已完成引导由 `[general].onboarded` 标记记录。
- **共享 Hooks 管理面板**：把设置页的 Hooks 管理区重构为可挂载的共享模块 `hook-panel.js`，引导页第二步与设置页「Hooks」分区均内嵌**同一实现**（注入 / 卸载 / 查看配置 / 配置路径 / Hook 事件详情 / 测试），消除重复代码。
- **按行配置对比（diff）**：配置变更预览改为基于 LCS 的按行对齐（git diff 风格），修复此前「插入一行后后续行被整体误标为增删」的问题。
- **托盘菜单**：新增「设置」与「引导面板」入口；移除托盘「检查更新」（设置面板内保留手动检查）。
- 设置页「关于」的版本号改为从应用运行时动态获取。

### 配置兼容性

- 新增 `[general]` 下的 `onboarded` 字段（默认 `false`），旧配置缺该字段时按默认值加载并展示一次引导页，无需迁移。
- 其余配置保持不变。

### 隐私

本版本未新增遥测、远程数据上报或外部服务。所有数据继续仅在本机采集、处理和显示。

### 平台与制品

- 本次 Release 计划提供以下安装包（draft 阶段，构建完成后上传）：
  - macOS Apple Silicon（arm64）DMG。
  - macOS Intel（x64）DMG。
  - Windows x86_64 NSIS 安装包。
  - Linux x86_64 deb 与 AppImage。
- 每个平台制品对应的 SHA-256 校验和见 Release 附件的 `SHA256SUMS`。
- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。首次启动时 Gatekeeper 可能要求用户手动允许。
- Windows 安装包未做代码签名，SmartScreen 可能要求用户手动确认首次安装。
- Linux 安装包未经分发渠道签名。

### 性能数据

本轮为引导页与 Hooks 管理重构，无运行时性能变化。

## English

### Highlights

- **First-run onboarding**: on the very first launch a welcome intro (the pet reacts to agent activity / inject hooks to sync state / data stays local) leads to the hook manager **in the same window** via Next; Done or Skip finishes onboarding. Completion is tracked by the `[general].onboarded` flag.
- **Shared hook management panel**: the settings hooks section is refactored into a mountable `hook-panel.js` module, embedded by both the onboarding second step and the settings "Hooks" section — one implementation for inject / uninstall / view-config / config path / hook-point details / test.
- **Line-based config diff**: config-change previews now use LCS line alignment (git-diff style), fixing the old index-based comparison that mislabeled every following line as changed after an insertion.
- **Tray menu**: added Settings and Onboarding entries; removed the tray "Check for Updates" item (the manual check stays in the settings panel).
- The About version in Settings is now fetched from the running app instead of a hardcoded string.

### Configuration compatibility

- A new `onboarded` field under `[general]` (defaults to `false`); existing configs without it load with the default and show the onboarding page once. No manual migration needed.
- All other settings are unchanged.

### Privacy

This release adds no telemetry, remote reporting, or external services. All data continues to be collected, processed, and displayed locally only.

### Platforms and artifacts

- This Release plans to include the following installers (draft stage; will be uploaded once built):
  - macOS DMG for Apple Silicon (arm64).
  - macOS DMG for Intel (x64).
  - Windows x86_64 NSIS installer.
  - Linux x86_64 deb and AppImage.
- SHA-256 checksums for each platform artifact are available in the `SHA256SUMS` release asset.
- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- The Linux packages are not signed by a distribution channel.

### Performance data

This round is an onboarding page and hook-management refactor; no runtime performance changes were introduced.
