# Familiar v1.2.1

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- **气泡向上堆叠且宠物位置保持不变**：桌面窗口调整尺寸时固定底边与水平中心，新增或移除任务气泡不再把宠物向下挤；macOS 使用原子窗口 Frame 更新，其他平台保留等价的锚定回退逻辑。
- **完整 Clippy 校验恢复通过**：将 hooks trait 的测试模块移到生产代码之后，消除 `items_after_test_module` 告警；不改变运行时行为。
- **本地配置忽略规则**：`.gemini/` 加入 Git 忽略列表，避免本机 Agent 配置被误提交。

### 配置兼容性

- 无配置结构或序列化格式变更，现有配置文件与精灵包可直接沿用。
- 无需执行配置迁移；升级并重启 Familiar 即可生效。

### 隐私

本版本没有新增遥测、远程数据上报或外部服务。Prompt、转录、文件内容与 hook 载荷继续仅在本机采集、处理和显示。

### 平台与制品

- macOS Apple Silicon（arm64）DMG。
- Windows x86_64 NSIS 安装包。
- Linux x86_64 deb 与 AppImage。
- 本版本不提供 macOS Intel（x64）DMG：该构建在 CI 中发现平台绑定类型不兼容，因此未将失败或未经验证的产物纳入正式发布。
- 各制品的 SHA-256 校验和见 Release 附件 `SHA256SUMS`。

### 签名状态

- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次启动时手动允许。
- Windows 安装包未做代码签名，SmartScreen 可能要求首次安装时手动确认。
- Linux 安装包未经分发渠道签名。

### 性能数据

本版本修复窗口定位并整理测试模块，没有引入可量化的运行时性能目标，因此未声明性能提升。

## English

### Highlights

- **Bubbles now stack upward without moving the pet**: window resizing keeps the bottom edge and horizontal center fixed, so adding or removing task bubbles no longer pushes the pet downward. macOS applies the frame change atomically; other platforms retain an equivalent anchored fallback.
- **Full Clippy validation restored**: moved the hook trait test module after production items to eliminate the `items_after_test_module` warning, with no runtime behavior change.
- **Local configuration ignore rule**: added `.gemini/` to Git ignores to prevent local agent configuration from being committed accidentally.

### Configuration compatibility

- No configuration schema or serialization changes; existing configuration files and sprite packs remain compatible.
- No migration is required. Upgrade and restart Familiar to apply the fix.

### Privacy

This release adds no telemetry, remote reporting, or external services. Prompts, transcripts, file contents, and hook payloads continue to be collected, processed, and displayed locally only.

### Platforms and artifacts

- macOS DMG for Apple Silicon (arm64).
- Windows x86_64 NSIS installer.
- Linux x86_64 deb and AppImage.
- No macOS Intel (x64) DMG is included in this release: CI exposed a platform-binding type incompatibility, so a failed or unverified artifact is not being shipped.
- SHA-256 checksums for every artifact are available in the `SHA256SUMS` Release asset.

### Signing status

- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- The Linux packages are not signed by a distribution channel.

### Performance data

This release fixes window positioning and reorganizes a test module. It has no quantified runtime performance target, so no performance improvement is claimed.
