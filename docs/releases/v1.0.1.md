# Familiar v1.0.1

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- **首次启动引导页（Onboard）**：应用首次打开时展示欢迎页，介绍 Familiar 的使用方式（桌宠随 Agent 活动变化、注入 Hooks 同步状态、数据本机处理），并提供「连接你的 Agent」卡片引导注入 Hooks——每个受支持的 Agent（Claude Code / Codex CLI / Qoder / Google Antigravity）显示注入状态，可一键注入（写入前 familiar 会先备份配置）。点击「开始使用」或「跳过」后不再重复弹出。

### 配置兼容性

- 新增 `[general]` 下的 `onboarded` 字段（默认 `false`）。旧配置文件不包含该字段时按默认值加载，首次启动仍会弹出引导页，无需手工迁移。
- 其余配置保持不变。

### 隐私

本版本未新增遥测、远程数据上报或外部服务。所有数据继续仅在本机采集、处理和显示。

### 平台与制品

- 本次 Release 计划提供以下安装包（draft 阶段，构建完成后上传）：
  - macOS Apple Silicon（arm64）DMG。
  - macOS Intel（x64）DMG。
  - Windows x86_64 NSIS 安装包。
  - Linux x86_64 deb 与 AppImage。
- 每个平台制品对应的 SHA-256 校验和见 Release 附件的 `SHA256SUMS`。
- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。首次启动时 Gatekeeper 可能要求用户手动允许。
- Windows 安装包未做代码签名，SmartScreen 可能要求用户手动确认首次安装。
- Linux 安装包未经分发渠道签名。

### 性能数据

本轮为首次启动引导页，无运行时性能变化。

## English

### Highlights

- **First-run onboarding page**: on the very first launch the app shows a welcome page that explains how Familiar works (the pet reacts to agent activity, inject hooks to sync agent state, data stays on your machine) and guides hook injection. Cards for every supported agent (Claude Code / Codex CLI / Qoder / Google Antigravity) show injection status with a one-click inject action (config is backed up before writing). The page stops appearing after you click **Get Started** or **Skip**.

### Configuration compatibility

- A new `onboarded` field is added under `[general]` (defaults to `false`). Existing config files without the field load with the default and still show the onboarding page once; no manual migration needed.
- All other settings are unchanged.

### Privacy

This release adds no telemetry, remote reporting, or external services. All data continues to be collected, processed, and displayed locally only.

### Platforms and artifacts

- This Release plans to include the following installers (draft stage; will be uploaded once built):
  - macOS DMG for Apple Silicon (arm64).
  - macOS DMG for Intel (x64).
  - Windows x86_64 NSIS installer.
  - Linux x86_64 deb and AppImage.
- SHA-256 checksums for each platform artifact are available in the `SHA256SUMS` release asset.
- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- The Linux packages are not signed by a distribution channel.

### Performance data

This round is a first-run onboarding page; no runtime performance changes were introduced.
