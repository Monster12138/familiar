# Familiar v2.4.1

[中文](#中文) | [English](#english)

## 中文

### 主要功能与修复

- 忽略 Codex 标题生成等内部线程使用的 `You are a helpful assistant. You will be presented with a user prompt` 提示，不再创建闲置气泡。
- 为持续处于 `Idle` 的会话增加自动清理，避免缺少结束事件时气泡永久残留。
- 设置页新增闲置会话清理时长，默认 600 秒（10 分钟），范围 60–3600 秒，保存后即时生效。

### 兼容性与配置迁移

- 版本元数据升级至 `2.4.1`。
- 新增 `renderer.desktop-pet.idle_session_timeout_secs` 配置字段；旧配置缺失该字段时自动使用 600 秒，无需手动迁移。
- 现有 Hook 配置和 `event_status_map` 保持兼容。

### 隐私影响

- 不新增遥测、网络上报或远程数据采集。
- 黑名单仅针对 Codex Hook 中已识别的内部提示前缀，不上传或持久化新的提示内容。

### 支持的平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64 NSIS 安装包。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。

## English

### Major features and fixes

- Ignore the `You are a helpful assistant. You will be presented with a user prompt` prompt prefix used by Codex internal threads such as title generation, so it no longer creates an idle bubble.
- Automatically clean up sessions that remain `Idle`, preventing bubbles from persisting when an end event is missing.
- Add an idle-session cleanup timeout setting, defaulting to 600 seconds (10 minutes), configurable from 60 to 3600 seconds and applied immediately after saving.

### Compatibility and configuration migration

- Version metadata is upgraded to `2.4.1`.
- Add `renderer.desktop-pet.idle_session_timeout_secs`; older configurations default to 600 seconds without manual migration.
- Existing Hook configuration and `event_status_map` remain compatible.

### Privacy impact

- No telemetry, network reporting, or remote data collection is added.
- The blacklist targets only the identified internal Codex Hook prompt prefix; no new prompt content is uploaded or persisted.

### Supported platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed.
