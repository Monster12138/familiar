# Familiar v2.3.0

[中文](#中文) | [English](#english)

## 中文

### 主要功能与修复

- 新增桌宠随机素材池：可在设置中将多个素材包加入随机池，启动时随机选择，并支持定时重抽与右键“换一只”。
- 优化素材包管理界面：随机池操作改为紧凑图标按钮，保留悬停说明和无障碍标签。
- 修复桌宠素材或气泡尺寸变化时窗口可能超出屏幕的问题。
- 新增 `scripts/animate_pack.py`，用于开发者生成和整理素材包 APNG；默认发布资源保持静态 PNG。
- 更新豆花与花卷桌宠素材资源。

### 兼容性与配置迁移

- 新增 `renderer.desktop-pet.sprite_pool` 配置字段，旧配置缺少该字段时默认使用空数组，无需手动迁移。
- `sprite_pool = []` 保持原有单素材包行为；只有加入至少两个有效素材包时才启用随机选择。
- 本版本继续兼容现有桌宠位置、悬停透明度、鼠标穿透和吸附配置。

### 隐私影响

- 不新增遥测、网络上报或远程数据采集。
- 随机素材选择、定时重抽和素材包处理均在本地完成。

### 支持的平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64 NSIS 安装包。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。

## English

### Major features and fixes

- Added a desktop-pet sprite pool: settings can include multiple packs in the pool, select one at launch, periodically reroll it, and manually choose “Shuffle Pet” from the context menu.
- Simplified the sprite-pack management UI: the random-pool control is now a compact icon button with tooltip and accessibility labeling retained.
- Fixed the pet window potentially moving off-screen when sprite or bubble dimensions change.
- Added `scripts/animate_pack.py` for developers to generate and finalize APNG sprite packs; shipped resources remain static PNGs by default.
- Updated the Douhua and Huajuan desktop-pet assets.

### Compatibility and configuration migration

- Added `renderer.desktop-pet.sprite_pool`. Older configurations default the missing field to an empty array, so no manual migration is required.
- `sprite_pool = []` preserves the existing single-pack behavior; random selection is enabled only when at least two valid packs are included.
- Existing desktop-pet positioning, hover-opacity, click-through, and snapping settings remain compatible.

### Privacy impact

- No telemetry, network reporting, or remote data collection is added.
- Random pack selection, periodic rerolls, and sprite-pack processing remain local-only.

### Supported platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed.
