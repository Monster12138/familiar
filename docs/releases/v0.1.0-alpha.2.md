# Familiar v0.1.0-alpha.2

This release focuses on making Familiar a lighter long-running desktop companion. It reduces unnecessary work while the app is idle without changing how agent activity is collected or displayed.

## Highlights

### Qoder integration

- Added local hook parsing and reporting for Qoder Agent sessions.
- Added Qoder to the hook settings and desktop activity presentation.
- Kept Qoder hook data within Familiar's local processing pipeline.

### Lower idle CPU usage

- Cached disk usage instead of enumerating APFS volumes every two seconds.
- Kept CPU and memory statistics responsive while refreshing slower-changing disk data less frequently.
- Paused system-stat polling while the dashboard is hidden.
- Prevented overlapping statistics requests when a previous refresh is still running.

### State updates only when needed

- Added state revisions so unchanged render state is no longer cloned, serialized, and sent to the WebView every 500ms.
- Limited settings-window updates to visible windows whose state has changed.
- Preserved the existing response time for real agent state transitions.

### Cached runtime configuration

- Loaded configuration into shared runtime state instead of reading and parsing TOML during every state refresh.
- Cached hidden-session settings and refreshed them when configuration changes.
- Kept runtime configuration synchronized after successful saves.

### Better UI resource cleanup

- Started and stopped dashboard polling with dashboard visibility.
- Released sprite image, canvas, manifest, and renderer references when the pixel renderer is destroyed.

## Measured impact

The macOS app was sampled before and after the changes under an idle workload:

| Metric | v0.1.0-alpha.1 | v0.1.0-alpha.2 |
|---|---:|---:|
| Short-window average CPU | ~2.6% | ~0.15% |
| CPU peak | 6.4% | 2.0% |
| Physical memory footprint | 45 MiB | 34.4 MiB |
| Peak physical footprint | 56 MiB | 48.5 MiB |
| Threads | 29–31 | 17–21 |

The post-optimization CPU median was 0% and P95 was 0.4% over a 30-second sample. Results vary by hardware, visible windows, agent activity, and sprite pack. Long-running memory behavior should continue to be monitored beyond the initial short-duration validation.

## Privacy

This release does not add telemetry or remote reporting. Prompts, transcripts, file contents, and hook payloads remain local.

## Upgrade notes

- No configuration migration is required.
- Existing configuration files and sprite packs remain compatible.
- Restart Familiar after replacing the application bundle so the new runtime and bundle version are loaded.
- The attached macOS build targets Apple Silicon (`arm64`).
- This alpha build is not signed with an Apple Developer ID and is not notarized. macOS Gatekeeper may require explicit approval before first launch.
