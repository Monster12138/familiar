# Familiar v0.3.0

[中文](#中文) | [English](#english)

## 中文

本版本为 Familiar 引入 Windows 平台支持，并提供首个 Windows 安装包（NSIS，x86_64）。macOS/Linux 的既有行为保持不变。

### 主要功能与修复

- **Windows 安装包**：新增 NSIS 打包链路，安装包内含 `familiar-cli` hook 上报组件（`resources/bin/`）与全部内置精灵包。
- **构建链路修复**：修正 Windows 下 `familiar-cli` 二进制解析（`bin_path`）；按平台拆分 Tauri 打包配置（Windows NSIS / macOS DMG）；补充 `icon.ico`。
- **精灵资源分发**：以 Vite 插件替代 git 软链接（`app/src/public/sprites`），开发模式带路径遍历防护地服务仓库精灵，构建时复制到解析后的输出目录，Windows 克隆仓库不再依赖软链接支持。
- **日志目录**：Windows 下默认日志目录改为 `%TEMP%`，不再硬编码 `/tmp`。
- **开机自启入口**：「打开登录项设置」在 Windows 打开启动文件夹、Linux 打开 autostart 目录；macOS 深链行为不变。
- **配置目录惯例**：新增 `familiar-core::platform` 目录助手，Windows 首选 `%APPDATA%\familiar`，旧版 `~/.config/familiar` 保留为回退；精灵目录沿用同一模式。
- **Hook 端点可配置**：`familiar-cli` 从用户配置读取 `hooks.socket_path` / `hooks.tcp_port`，不再硬编码。
- **设置页平台适配**：Windows 隐藏 Unix 域套接字路径项；非 macOS 隐藏仅 macOS 生效的「跟随桌面切换」项；自启文案平台中立化（中英双语）。
- **透明窗口**：关闭宠物窗口的系统阴影，消除 Windows 上透明窗的淡色 DWM 描边。
- **应用图标**：Windows / macOS 应用图标改为内置精灵「小虎」（tabby-cat）「干活中」动作的像素图，并补齐 macOS `icon.icns`。
- **捆绑默认配置**：安装包随带 `config/default.toml` 作为出厂默认（只读加载，设置保存不会回写该文件）；默认素材改为小虎（tabby-cat），默认位置 `bottom-right`，打包默认值不再包含本机坐标。

### 兼容性

- 无需配置迁移；旧版配置文件与精灵包保持兼容。
- Windows 上旧版位于 `~/.config/familiar` 的配置仍会被回退读取。

### 隐私

- 未新增任何遥测或远程上报；prompt、转录、文件内容与 hook 载荷仍完全保留在本地。

### 支持平台

- Windows x86_64（NSIS 安装包，本版本附件）。
- macOS（Apple Silicon）与 Linux 代码兼容；本版本未附 macOS DMG 制品。

### 签名状态

- Windows 安装包当前未做代码签名，SmartScreen 可能在首次安装时要求手动确认。
- 本版本未附 macOS 构建，签名/公证状态沿用上一版本说明。

## English

This release adds Windows platform support to Familiar, including the first Windows installer (NSIS, x86_64). Existing macOS/Linux behavior is unchanged.

### Highlights

- **Windows installer**: NSIS bundling ships the `familiar-cli` hook reporter (`resources/bin/`) and all built-in sprite packs.
- **Build pipeline fixes**: `familiar-cli` binary resolution on Windows (`bin_path`); platform-split Tauri bundle configs (NSIS on Windows, DMG on macOS); added `icon.ico`.
- **Sprite distribution**: a Vite plugin replaces the git symlink (`app/src/public/sprites`), serving repo sprites in dev with a path-traversal guard and copying them into the resolved build output; Windows clones no longer need symlink support.
- **Log directory**: defaults to `%TEMP%` on Windows instead of a hardcoded `/tmp`.
- **Autostart entry**: "open login items" now opens the Windows Startup folder / Linux autostart dir; the macOS deep link is unchanged.
- **Platform config locations**: new `familiar-core::platform` helpers; Windows prefers `%APPDATA%\familiar` with legacy `~/.config/familiar` retained as fallback; sprite dirs follow the same pattern.
- **Configurable hook endpoints**: `familiar-cli` reads `hooks.socket_path` / `hooks.tcp_port` from user config instead of hardcoded values.
- **Settings platform adaptation**: the Unix-socket-path item is hidden on Windows; the macOS-only "follow desktop switching" item is hidden on non-macOS; autostart copy is platform-neutral (zh + en).
- **Transparent window**: OS shadow disabled on the pet window, removing the faint DWM outline on Windows.
- **App icon**: the Windows/macOS application icon now uses the "working" pose of the built-in tabby-cat sprite (Xiaohu); the macOS `icon.icns` is now generated as well.
- **Bundled default config**: the installer ships `config/default.toml` as a read-only factory default (saving settings never rewrites it); the default sprite is now `tabby-cat` and the default position `bottom-right`, so machine-local coordinates are no longer packaged.

### Compatibility

- No configuration migration required; existing config files and sprite packs remain compatible.
- Legacy `~/.config/familiar` configs are still read as a fallback on Windows.

### Privacy

- No telemetry or remote reporting added; prompts, transcripts, file contents, and hook payloads remain local.

### Supported platforms

- Windows x86_64 (NSIS installer, attached in this release).
- macOS (Apple Silicon) and Linux remain code-compatible; no macOS DMG artifact is attached in this release.

### Signing status

- The Windows installer is not code-signed; SmartScreen may ask for manual confirmation on first install.
- No macOS build is attached; see the previous release for its signing/notarization status.
