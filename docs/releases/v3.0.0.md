# Familiar v3.0.0

[中文](#中文) | [English](#english)

## 中文

### 主要功能与修复

- 新增创意工坊独立窗口，可从设置页侧边栏或素材包管理区打开。支持新建素材包、编辑自定义包，以及复制内置包后改编。
- 可为各状态选择或拖入 PNG、APNG、GIF、WebP、SVG 图片；点击状态行即可预览，预览保持原始宽高比。只有名称和 `idle` 图片为必填项，素材包标识符由应用自动生成。
- 保存前校验图片和素材包大小、格式与路径；编辑已有自定义包时保留本地备份。保存后刷新素材列表和正在使用的桌宠。支持删除自定义包及导出已保存作品为 `.fpack`。
- 切换素材包或关闭有未保存改动的工坊窗口时，在窗口内确认，避免阻塞其他窗口。补齐中英文界面文案，并使工坊配色与设置面板一致。

### 兼容性与配置迁移

- 版本元数据升级至 `3.0.0`。现有素材包仍使用 `pack.json` Format Version 1 和 `.fpack` 格式，无需迁移；现有配置和 Hook 安装不需要更改。
- 内置素材包仍可直接使用，但须复制为自定义包后才能在工坊修改。

### 隐私影响

- 工坊在本机读取、保存和导出图片，不上传素材，也不新增遥测或远程服务。

### 支持的平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64 NSIS 安装包。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。

## English

### Major features and fixes

- Add a separate Creative Workshop window, accessible from the settings sidebar and pack management area. Create packs, edit custom packs, or make an editable copy of a built-in pack.
- Choose or drop PNG, APNG, GIF, WebP, and SVG images for each state. Click a state to preview it at its original aspect ratio. Only the name and `idle` image are required; the app generates pack identifiers.
- Validate image and pack sizes, formats, and paths before saving. Keep a local backup when editing a custom pack. Saving refreshes the pack list and active desktop pet. Custom packs can be deleted, and saved work can be exported as `.fpack`.
- Confirm unsaved changes inside the workshop window when switching packs or closing it, without blocking other windows. Add Chinese and English UI text and align workshop colors with the settings panel.

### Compatibility and configuration migration

- Version metadata is upgraded to `3.0.0`. Existing packs still use `pack.json` Format Version 1 and the `.fpack` format; no migration is needed. Existing configuration and Hook installations do not need changes.
- Built-in packs remain usable as before, but must be copied before editing in the workshop.

### Privacy impact

- The workshop reads, saves, and exports images locally. It adds no asset uploads, telemetry, or remote service.

### Supported platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed.
