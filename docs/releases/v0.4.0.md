# Familiar v0.4.0

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- 新增经典仪表和极简数字两种系统资源仪表样式。
- 支持 CPU、内存和磁盘指标按水平或纵向布局。
- 支持将仪表放置在宠物左侧、下方或右侧，并配置侧边仪表的顶部、居中或底部对齐方式。
- 将显示设置整理为“宠物”“仪表”“气泡”三个分组，并统一配置项排序。
- 修复宽仪表布局可能被桌面窗口裁切的问题。

### 配置兼容性

- 旧配置缺少新增字段时，默认使用经典仪表、宠物下方、纵向布局和底部对齐。
- 已移除的单行胶囊样式会自动回退为经典仪表，避免旧配置加载失败。

### 隐私

本版本没有新增遥测、远程数据上报或外部服务。CPU、内存和磁盘数据继续仅在本机采集和显示。

### 平台与制品

- 本次 Release 提供 Apple Silicon（arm64）macOS DMG。
- Windows x86_64 与 Linux x86_64 源码仍受支持，但本次 Release 未在对应平台构建安装包。
- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。首次启动时 Gatekeeper 可能要求用户手动允许。

## English

### Highlights

- Added classic gauges and minimal numbers as system resource dashboard styles.
- Added horizontal and vertical layouts for CPU, memory, and disk metrics.
- Added left, bottom, and right dashboard placement, with top, center, or bottom alignment for side placement.
- Reorganized display settings into Pet, Dashboard, and Bubble groups with consistent control ordering.
- Fixed desktop-window clipping for wider dashboard layouts.

### Configuration compatibility

- Existing configurations without the new fields default to classic gauges, bottom placement, vertical layout, and bottom alignment.
- The removed single-line capsule style automatically falls back to classic gauges so older configurations continue to load.

### Privacy

This release adds no telemetry, remote reporting, or external services. CPU, memory, and disk data continues to be collected and displayed locally only.

### Platforms and artifacts

- This Release includes a macOS DMG for Apple Silicon (arm64).
- The source continues to support Windows x86_64 and Linux x86_64, but installers were not built on those platforms for this Release.
- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
