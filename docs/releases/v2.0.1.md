# Familiar v2.0.1

[中文](#中文) | [English](#english)

## 中文

### 修复

- 修复 macOS Intel（x86_64）桌面包构建失败的问题：调用 Cocoa `setFrame:display:` 时使用平台正确的 Objective-C `BOOL` 常量。
- 版本号统一升级至 `2.0.1`。

### 兼容性与配置迁移

- 本版本不改变配置格式、远程订阅协议或默认部署模式，无需迁移配置。

### 隐私影响

- 不新增遥测或外部上报；本版本仅修复 macOS 构建兼容性。

### 平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；Windows x86_64 NSIS 安装包。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本为构建兼容性修复，未建立新的可复现端到端性能基线，也不宣称量化性能变化。

## English

### Fixes

- Fixed macOS Intel (x86_64) desktop bundle builds by passing Cocoa's platform-correct Objective-C `BOOL` constant to `setFrame:display:`.
- Unified the release version at `2.0.1`.

### Compatibility and configuration migration

- This release does not change the configuration format, remote subscription protocol, or default deployment mode; no configuration migration is required.

### Privacy impact

- No telemetry or external reporting is added; this release only fixes macOS build compatibility.

### Platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; Windows x86_64 NSIS installer.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

This is a build-compatibility fix release. No new reproducible end-to-end performance baseline was established, and no quantified performance change is claimed.
