# Familiar v0.4.2

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- 修复 Windows 设置界面下拉选项对比度不足的问题，深色与浅色主题下选项文字均清晰可读。
- 修复 Windows 托盘图标显示为空白方块的问题，托盘区现在会显示内嵌的应用图标。
- 发布流程升级为跨平台自动化构建，本次 Release 首次同时提供 macOS、Windows 与 Linux 安装包，并统一了产物命名（文件名内嵌平台名）。

### 配置兼容性

- 本版本没有配置格式变更，旧配置可直接沿用。

### 隐私

本版本没有新增遥测、远程数据上报或外部服务。所有数据继续仅在本机采集、处理和显示。

### 平台与制品

- 本次 Release 提供以下安装包：
  - macOS Apple Silicon（arm64）DMG。
  - macOS Intel（x64）DMG。
  - Windows x86_64 NSIS 安装包。
  - Linux x86_64 deb 与 AppImage。
- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。首次启动时 Gatekeeper 可能要求用户手动允许。
- Windows 安装包未做代码签名，SmartScreen 可能要求用户手动确认首次安装。
- Linux 安装包未经分发渠道签名。

## English

### Highlights

- Fixed poor contrast of settings dropdown options on Windows; option text is now clearly readable in both dark and light themes.
- Fixed the blank tray icon square on Windows by embedding the application icon into the tray.
- Upgraded the release pipeline to automated cross-platform builds. This Release provides macOS, Windows, and Linux installers for the first time, with unified artifact names that embed the platform name.

### Configuration compatibility

- No configuration format changes in this release; existing configurations continue to work as-is.

### Privacy

This release adds no telemetry, remote reporting, or external services. All data continues to be collected, processed, and displayed locally only.

### Platforms and artifacts

- This Release includes the following installers:
  - macOS DMG for Apple Silicon (arm64).
  - macOS DMG for Intel (x64).
  - Windows x86_64 NSIS installer.
  - Linux x86_64 deb and AppImage.
- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- The Linux packages are not signed by a distribution channel.
