# Familiar v0.5.0

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- Hooks 配置面板重构：每个 Agent 以可折叠卡片展示全部 Hook 点，支持查看事件名称、执行命令与匹配器（Matcher）。
- Hook 点手动测试：支持通过事件总线直接发送模拟事件，桌宠应数秒内响应；同时提供"复制命令"按钮，命令内嵌模拟输入（`--stdin-json`），可在 cmd、PowerShell 与 sh 中直接粘贴执行。
- 设置面板统一通知渠道：保存中、已保存、保存失败、Hook 测试结果等瞬时状态统一以底部 Toast 展示，替换原角落指示器与行内提示，避免长文本被截断。
- 会话管理：活动会话卡片新增"隐藏"与"删除"图标按钮。隐藏会话不再显示在桌宠气泡中；删除会话立即从会话列表与桌宠状态中移除。

### 配置兼容性

- `sessions.hidden_sessions` 字段保持不变，旧配置可直接沿用。

### 隐私

本版本没有新增遥测、远程数据上报或外部服务。所有数据继续仅在本机采集、处理和显示。

### 平台与制品

- 本次 Release 计划提供以下安装包（draft 阶段，构建完成后上传）：
  - macOS Apple Silicon（arm64）DMG。
  - Windows x86_64 NSIS 安装包。
  - Linux x86_64 deb 与 AppImage。
- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。首次启动时 Gatekeeper 可能要求用户手动允许。
- Windows 安装包未做代码签名，SmartScreen 可能要求用户手动确认首次安装。
- Linux 安装包未经分发渠道签名。

## English

### Highlights

- Reworked the Hooks settings panel: each agent is shown as a collapsible card listing every hook point with its event name, command, and matcher.
- Manual hook-point testing: publish a simulated event through the event bus and the pet should respond within seconds; a "Copy Command" action embeds mocked input (`--stdin-json`) that works in cmd, PowerShell, and sh.
- Unified notification channel in the settings panel: transient states (saving, saved, save failed, hook test results) are now shown as a bottom toast instead of corner indicators or inline labels, avoiding truncated messages.
- Session management: active session cards now have "hide" and "delete" icon buttons. Hidden sessions disappear from pet bubbles; deleted sessions are removed from the session list and pet state immediately.

### Configuration compatibility

- The `sessions.hidden_sessions` field is unchanged; existing configurations continue to work as-is.

### Privacy

This release adds no telemetry, remote reporting, or external services. All data continues to be collected, processed, and displayed locally only.

### Platforms and artifacts

- This Release plans to include the following installers (draft stage; will be uploaded once built):
  - macOS DMG for Apple Silicon (arm64).
  - Windows x86_64 NSIS installer.
  - Linux x86_64 deb and AppImage.
- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- The Linux packages are not signed by a distribution channel.
