# Familiar v2.2.1

[中文](#中文) | [English](#english)

## 中文

### 主要功能与修复

- 修复 macOS 创建的 `.fpack` 包含 `__MACOSX` 元数据目录时无法导入的问题，并拒绝含多个素材清单的歧义压缩包。
- 修复用户导入素材与内置素材 ID 相同时错误使用内置版本的问题；用户素材现在按设计优先，并通过资源修订号及时失效 WebView 缓存。
- 启用 Tauri 本地素材 asset protocol，仅授权 Familiar 的用户素材目录，修复花卷、豆花等自定义素材图片无法加载的问题。
- 覆盖导入当前正在使用的素材包后，桌宠会立即重新加载，无需切换素材或重启。
- 素材管理新增用户导入素材删除功能：内置素材不可删除，当前使用的素材需先切换，删除采用两次点击确认并带路径穿越防护。
- 移除内置豆花素材，使用新版花卷图片替换内置花卷并同步更新分发用 `.fpack`。
- 精简素材卡片文案和操作：移除冗长描述后缀，“使用此素材包”简化为“使用”，预览动作改为图标按钮。

### 兼容性与配置迁移

- 不新增或修改用户配置字段，无需手动迁移配置。
- 如果现有配置选择了已移除的内置豆花且用户目录也没有豆花包，应用会沿用现有素材缺失回退逻辑选择可用内置素材。
- 用户导入素材仍存放在平台约定的 Familiar 素材目录；macOS/Linux 为 `~/.config/familiar/sprites`，Windows 为应用数据目录下的 `familiar/sprites`。
- 自定义素材删除仅允许单层素材 ID，不能访问素材目录之外的路径。

### 隐私影响

- 不新增遥测、网络上报或数据采集。
- Tauri asset protocol 仅允许 WebView 读取 Familiar 用户素材目录，不开放 Home、文档或其他个人目录。
- 素材导入、缓存修订、刷新和删除均在本地完成。

### 支持的平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64 NSIS 安装包；Windows 本地 Hook 使用 loopback TCP。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。

## English

### Major features and fixes

- Fixed imports of `.fpack` archives created on macOS when they contain a `__MACOSX` metadata directory, and reject ambiguous archives containing multiple pack manifests.
- Fixed user-imported packs being shadowed by bundled packs with the same ID. User packs now take precedence as designed, with asset revisions invalidating stale WebView caches.
- Enabled Tauri's local asset protocol with a narrow scope limited to Familiar's user sprite directories, fixing failed custom images such as Huajuan and Douhua.
- Re-importing the currently active pack now reloads the desktop pet immediately without switching packs or restarting.
- Added deletion for user-imported packs. Bundled packs cannot be deleted, active packs must be switched first, deletion uses two-click confirmation, and path traversal is rejected.
- Removed the bundled Douhua pack, replaced bundled Huajuan artwork with the new version, and synchronized the distributable `.fpack` archive.
- Simplified pack-card copy and controls by removing the verbose description suffix, shortening the use action, and making preview an icon-only button.

### Compatibility and configuration migration

- No user configuration fields are added or changed; no manual configuration migration is required.
- If an existing configuration selects the removed bundled Douhua pack and no user-imported Douhua pack exists, the existing missing-pack fallback selects an available bundled pack.
- Imported packs remain under Familiar's platform-specific sprite directory: `~/.config/familiar/sprites` on macOS/Linux and `familiar/sprites` under the application data directory on Windows.
- Custom-pack deletion only accepts a single pack ID and cannot access paths outside the sprite directory.

### Privacy impact

- No telemetry, network reporting, or data collection is added.
- Tauri's asset protocol only allows the WebView to read Familiar's user sprite directory; Home, Documents, and other personal directories are not exposed.
- Pack import, cache revision, reload, and deletion all run locally.

### Supported platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer; Windows local Hook ingest uses loopback TCP.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed.
