# Familiar v0.3.1

[中文](#中文) | [English](#english)

## 中文

本版本为 Familiar 提供首个 Linux x86_64 安装包（deb 与 AppImage），并同步重新发布 Windows 安装包。无应用代码行为变更。

### 主要功能与修复

- **Linux 安装包**：新增 deb 与 AppImage 打包产物（x86_64），安装包内含 `familiar-cli` hook 上报组件（`resources/bin/`）、`config/default.toml` 出厂默认配置与全部内置精灵包；deb 的运行期依赖（`libwebkit2gtk-4.1-0` 等）由包元数据自动声明。
- **Linux 兼容性验证**：在 Ubuntu 24.04（含 WSL2/WSLg）完成全量验证——`cargo test`（27 项全部通过）、`cargo clippy -D warnings`（零警告）；主窗口（透明 + 无边框）、桌面宠物窗口与 hook 事件链路（UDS `/tmp/familiar.sock`）均正常工作。
- **发布流程文档**：`RELEASE_PROCESS.md` 新增 Linux（x86_64）打包章节与制品归档约定。
- **CI**：GitHub Actions Rust 工作流补齐 Linux 系统依赖安装与 `familiar-cli` bundle 资源构建步骤。

### 兼容性

- 无应用代码变更，无需配置迁移；旧版配置文件与精灵包保持兼容。
- AppImage 运行需要 FUSE；缺少 FUSE 的环境可安装 deb，或使用 `--appimage-extract-and-run` 方式启动。
- WSLg 下调试启动 GUI 如遇渲染问题，可设置 `WEBKIT_DISABLE_DMABUF_RENDERER=1 LIBGL_ALWAYS_SOFTWARE=1 GDK_BACKEND=x11`；WSLg 无系统托盘宿主，托盘图标不显示。

### 隐私

- 未新增任何遥测或远程上报；prompt、转录、文件内容与 hook 载荷仍完全保留在本地。

### 支持平台

- Linux x86_64（deb / AppImage，本版本附件）。
- Windows x86_64（NSIS 安装包，本版本附件）。
- macOS（Apple Silicon）代码兼容；本版本未附 macOS DMG 制品。

### 签名状态

- Linux 安装包未做签名，安装来源未经分发渠道签名。
- Windows 安装包未做代码签名，SmartScreen 可能在首次安装时要求手动确认。
- 本版本未附 macOS 构建，签名/公证状态沿用上一版本说明。

## English

This release ships the first Linux x86_64 installers for Familiar (deb and AppImage), together with a rebuilt Windows installer. There are no application behavior changes.

### Highlights

- **Linux installers**: new deb and AppImage artifacts (x86_64) bundling the `familiar-cli` hook reporter (`resources/bin/`), the `config/default.toml` factory default, and all built-in sprite packs; deb runtime dependencies (`libwebkit2gtk-4.1-0` etc.) are declared in package metadata.
- **Linux compatibility verified**: full validation on Ubuntu 24.04 (including WSL2/WSLg) — `cargo test` (27 tests passing), `cargo clippy -D warnings` (zero warnings); the main window (transparent + undecorated), the desktop pet window, and the hook event pipeline (UDS `/tmp/familiar.sock`) all work correctly.
- **Release process docs**: `RELEASE_PROCESS.md` gains a Linux (x86_64) packaging section and artifact archival conventions.
- **CI**: the GitHub Actions Rust workflow now installs Linux system dependencies and builds the `familiar-cli` bundle resource before the workspace build.

### Compatibility

- No application code changes; no configuration migration required; existing config files and sprite packs remain compatible.
- The AppImage requires FUSE at runtime; environments without FUSE can install the deb or run with `--appimage-extract-and-run`.
- On WSLg, set `WEBKIT_DISABLE_DMABUF_RENDERER=1 LIBGL_ALWAYS_SOFTWARE=1 GDK_BACKEND=x11` if GUI rendering misbehaves; the tray icon is unavailable because WSLg has no tray host.

### Privacy

- No telemetry or remote reporting added; prompts, transcripts, file contents, and hook payloads remain local.

### Supported platforms

- Linux x86_64 (deb / AppImage, attached in this release).
- Windows x86_64 (NSIS installer, attached in this release).
- macOS (Apple Silicon) remains code-compatible; no macOS DMG artifact is attached in this release.

### Signing status

- The Linux packages are unsigned; the install source is not signed by a distribution channel.
- The Windows installer is not code-signed; SmartScreen may ask for manual confirmation on first install.
- No macOS build is attached; see the previous release for its signing/notarization status.
