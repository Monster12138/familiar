# Familiar v2.1.1

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- 将默认的 `AgentStarted` 行为映射为 `Idle`（空闲），避免 Agent 刚启动时直接显示为工作中。
- 同步更新设置页事件映射表和 Hook 预览面板中的默认状态说明。

### 合并自 v2.1.0 的更新

- 新增「悬停时隐藏」设置，可在鼠标进入整个桌宠窗口时暂时隐藏窗口内容。
- 悬停隐藏覆盖桌宠、气泡、状态面板和远程模式标识，不改变窗口位置或尺寸。
- 设置项支持自动保存，并增加鼠标穿透依赖提示。
- 新增 `renderer.desktop-pet.hide_on_hover` 配置字段。

### 兼容性与配置迁移

- 仅调整未配置 `event_status_map.AgentStarted` 时的内置默认行为。
- 如果用户已在配置中显式设置 `AgentStarted`，该设置保持不变。
- 旧配置缺少 `hide_on_hover` 时默认值为 `false`，无需手动迁移。
- 要使用悬停隐藏，必须关闭「鼠标穿透」；鼠标穿透开启时系统不会向窗口发送悬停事件。
- 本版本不改变配置格式、远程订阅协议或默认部署模式。

### 隐私影响

- 不新增遥测、网络上报或数据采集行为。
- 该变更仅影响本地状态机和界面状态展示。
- 悬停检测与隐藏均在本地桌面端完成，不发送鼠标位置或窗口状态。

### 平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64 NSIS 安装包；Windows 本地 Hook 使用 loopback TCP。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。

## English

### Highlights

- Changed the built-in default for `AgentStarted` to `Idle`, so a newly started Agent is not shown as working before activity begins.
- Synchronized the default status shown in the Settings event mapping table and Hook preview panel.

### Updates merged from v2.1.0

- Added a **Hide on Hover** setting that temporarily hides the entire desktop window content when the pointer enters it.
- Hover hiding covers the pet, bubbles, statistics panel, and remote-mode indicator without changing the window position or size.
- Added auto-save support for the setting and a concise Click-Through dependency hint.
- Added the `renderer.desktop-pet.hide_on_hover` configuration field.

### Compatibility and configuration migration

- Only the built-in behavior is changed when `event_status_map.AgentStarted` is not configured.
- An explicit user mapping for `AgentStarted` remains unchanged.
- Older configurations missing `hide_on_hover` default to `false`; no manual migration is required.
- Click-Through must be disabled for hover hiding because the operating system does not deliver hover events to an ignored window.
- This release does not change the configuration format, remote subscription protocol, or default deployment mode.

### Privacy impact

- No telemetry, network reporting, or data collection behavior is added.
- The change only affects the local state machine and UI status presentation.
- Hover detection and hiding run entirely in the local desktop client; pointer coordinates and window state are not transmitted.

### Platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer; Windows local Hook ingest uses loopback TCP.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed.
