# Familiar v0.5.1

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- Claude Code Hooks 与官方文档对齐：
  - 注入的 hook 事件从 2 个（`PreToolUse`、`PostToolUse`）扩展到 10 个官方支持的事件：`SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`PostToolUseFailure`、`PermissionRequest`、`SubagentStart`、`SubagentStop`、`Stop`、`SessionEnd`。
  - 工具类事件（`PreToolUse`、`PostToolUse`、`PostToolUseFailure`、`PermissionRequest`）补上官方 `matcher: "*"` 字段，匹配全部工具。
  - Hook 响应改为完全被动：所有事件退出码 0、stdout 为空。不再向 agent 上下文注入 JSON 噪音，也绝不覆盖用户自行配置的权限或拒绝规则。
  - `SubagentStart`/`SubagentStop` 事件现在解析官方 `subagent_type` 字段，而非硬编码 `Unknown`。

### 配置兼容性

- `~/.claude/settings.json` 的 `hooks` 结构不变。
- 已注入过旧版（仅 `PreToolUse`/`PostToolUse`）的用户需要重新执行"注入"操作以获取全部 10 个事件；重新注入会自动合并，不会覆盖已有的其它 hook。
- Claude Code 的 hooks 在会话启动时加载：注入完成后需重启 Claude Code 会话（新开 `claude` 或 `cc`）才生效。

### 隐私

本版本没有新增遥测、远程数据上报或外部服务。hook 保持完全被动，不覆盖用户权限规则；所有数据继续仅在本机采集、处理和显示。

### 平台与制品

- 本次 Release 计划提供以下安装包（draft 阶段，构建完成后上传）：
  - macOS Apple Silicon（arm64）DMG。
  - Windows x86_64 NSIS 安装包。
  - Linux x86_64 deb 与 AppImage。
- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。首次启动时 Gatekeeper 可能要求用户手动允许。
- Windows 安装包未做代码签名，SmartScreen 可能要求用户手动确认首次安装。
- Linux 安装包未经分发渠道签名。

### 性能数据

本次为配置与集成修复，无新增运行时性能变化。

## English

### Highlights

- Claude Code hooks aligned with the official documentation:
  - The injected hook set grows from 2 (`PreToolUse`, `PostToolUse`) to the 10 officially supported events: `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `SubagentStart`, `SubagentStop`, `Stop`, `SessionEnd`.
  - Tool-scoped events (`PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`) now carry the official `matcher: "*"` to match all tools.
  - Hook responses are fully passive: every event exits `0` with empty stdout. Hooks never inject JSON noise into the agent context and never override the user's own permission or deny rules.
  - `SubagentStart`/`SubagentStop` now parse the official `subagent_type` field instead of hardcoding `Unknown`.

### Configuration compatibility

- The `hooks` structure in `~/.claude/settings.json` is unchanged.
- Users who previously injected the older two-event set should run the injection step again to pick up all 10 events; re-injecting merges cleanly without overwriting other hooks.
- Claude Code loads hooks at session start: after injecting, restart the Claude Code session (start a fresh `claude` or `cc`) for the new events to take effect.

### Privacy

This release adds no telemetry, remote reporting, or external services. Hooks stay fully passive and never override user permission rules; all data continues to be collected, processed, and displayed locally only.

### Platforms and artifacts

- This Release plans to include the following installers (draft stage; will be uploaded once built):
  - macOS DMG for Apple Silicon (arm64).
  - Windows x86_64 NSIS installer.
  - Linux x86_64 deb and AppImage.
- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- The Linux packages are not signed by a distribution channel.

### Performance data

This is a configuration and integration fix; no runtime performance changes were introduced.
