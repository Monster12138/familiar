# Familiar v2.4.0

[中文](#中文) | [English](#english)

## 中文

### 主要功能与修复

- 新增不可见的 `SessionStarted` 内部事件：各 Agent 的 `SessionStart` 不再创建或刷新可见 Agent、宠物状态、气泡或图标。
- 将用户提交消息作为可感知生命周期的起点：`UserPromptSubmit` 之后继续展示思考、工作、等待、完成或失败状态。
- 新增 Agent Hook → 宠物状态 → 气泡状态矩阵文档，覆盖 Claude Code、Codex、Antigravity、Qoder 和 DeepSeek Harness。
- Hook 面板预览与后端行为保持一致，`SessionStart` 显示为“保持当前气泡和图标”。

### 兼容性与配置迁移

- 版本元数据升级至 `2.4.0`。
- 不新增或修改用户配置字段，无需手动迁移配置。
- 现有 Agent Hook 配置结构保持兼容；`SessionStart` 仍会被接收，但仅作为不可见的会话初始化信号处理。
- 现有 `event_status_map` 配置保持兼容；`SessionStarted` 不作为可配置的可见状态，用户提交消息仍使用 `AgentStarted` 的原有映射。

### 隐私影响

- 不新增遥测、网络上报或远程数据采集。
- `SessionStart` 不再把会话初始化信息提升为可见 Agent 或气泡，减少本地 UI 暴露的非必要会话信息。

### 支持的平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64 NSIS 安装包。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。

## English

### Major features and fixes

- Added an invisible `SessionStarted` internal event: an Agent `SessionStart` no longer creates or refreshes a visible Agent, desktop-pet state, bubble, or icon.
- Made the user's submitted message the start of the observable lifecycle: after `UserPromptSubmit`, thinking, working, waiting, completion, and failure states continue to be shown as before.
- Added an Agent Hook → pet state → bubble state matrix covering Claude Code, Codex, Antigravity, Qoder, and DeepSeek Harness.
- Aligned the Hook panel preview with backend behavior; `SessionStart` is shown as “Keep current bubble and icon”.

### Compatibility and configuration migration

- Version metadata is upgraded to `2.4.0`.
- No user configuration fields are added or changed, so no manual migration is required.
- Existing Agent Hook configuration structures remain compatible; `SessionStart` is still accepted but is handled only as an invisible session-initialization signal.
- Existing `event_status_map` configuration remains compatible; `SessionStarted` is not exposed as a configurable visible state, while user prompts continue to use the existing `AgentStarted` mapping.

### Privacy impact

- No telemetry, network reporting, or remote data collection is added.
- `SessionStart` no longer promotes session initialization into a visible Agent or bubble, reducing unnecessary session information exposed in the local UI.

### Supported platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed.
