# Familiar v3.0.1

[中文](#中文) | [English](#english)

## 中文

### 主要功能与修复

- 新增“全屏时自动隐藏”选项。启用后，macOS 和 Windows 上的桌宠会在前台应用占满桌宠所在屏幕时隐藏，并在退出全屏后恢复。Linux 不显示此选项。
- 自动恢复桌宠时不再激活宠物窗口，避免打断当前应用的键盘输入焦点。Windows 使用不激活窗口的显示方式，并配对原生显示/隐藏调用，保证连续全屏切换仍能正常工作。
- 优化中英文 README 的导航、安装信息和首次启动说明。

### 兼容性与配置迁移

- 版本元数据升级至 `3.0.1`。新增配置 `renderer.desktop-pet.hide_on_fullscreen`，默认值为 `false`；旧配置无需迁移，现有桌宠行为保持不变。
- 全屏隐藏目前支持 macOS 和 Windows 桌面应用；Linux 不支持此功能，也不显示相关选项。

### 隐私影响

- 全屏检测在本机读取前台应用的窗口边界和进程信息，用于判断其是否占满桌宠所在屏幕；不会读取窗口标题或屏幕内容，也不会新增遥测或远程传输。

### 支持的平台与架构

- macOS 桌面包：Apple Silicon（arm64）与 Intel（x86_64）。
- Linux x86_64：deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64：NSIS 安装包。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。

## English

### Major features and fixes

- Add an **Auto-hide in fullscreen** setting. When enabled, the pet hides when the foreground app fills the pet's display on macOS and Windows, then returns after fullscreen ends. The setting is hidden on Linux.
- Restore the pet without activating its window, preserving keyboard focus in the current app. Windows uses a non-activating show operation paired with native hide/show calls so repeated fullscreen transitions continue to work.
- Improve navigation, installation information, and first-launch guidance in both READMEs.

### Compatibility and configuration migration

- Version metadata is upgraded to `3.0.1`. The new `renderer.desktop-pet.hide_on_fullscreen` setting defaults to `false`; existing configurations need no migration and retain their current behavior.
- Fullscreen auto-hide is supported on macOS and Windows desktop apps. Linux does not support this feature and does not show the setting.

### Privacy impact

- Fullscreen detection reads foreground window bounds and process information locally to determine whether the app fills the pet's display. It does not read window titles or screen contents, and adds no telemetry or remote transfer.

### Supported platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed.
