# Familiar v1.2.0

[中文](#中文) | [English](#english)

## 中文

### 主要更新

- **DeepSeek Harness（DSH）Hooks 集成**：新增 `AgentSource::DeepSeekHarness` 事件来源与 `DeepSeekHarnessHook` 管理模块。Familiar 现在可识别来自 DeepSeek Harness 的活动（读写文件、运行命令、搜索、子 agent 等），桌面宠物与设置面板以独立的 **DSH** 徽章显示，与 Claude Code / Codex / Qoder / Antigravity 区分。
  - 独立的 hooks 配置文件（`~/.dsh/familiar-hooks.json`），可在设置面板中注入、预览与卸载；命令使用 `--source deepseek-harness` 标记。
  - 仅注入 DSH `dsh-hooks-claude-code` 桥接实际支持的 7 个事件（`SessionStart`、`UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`Stop`、`SubagentStart`、`SubagentStop`），避免死配置。
- **Windows hooks 崩溃修复**：DSH 桥接在 Windows 上通过 PowerShell 执行 hook 命令时，命令路径改为无引号裸路径（PowerShell 5.1 无法解析带引号路径+参数）；`bin_path` 在开发构建下优先解析 release 版 CLI（debug 版依赖 MSVC 调试运行库，在 GUI 宿主环境下可能初始化失败）。
- **备用扫描目录扩展**：hooks 备份清理扫描新增 `~/.dsh` 目录。
- **桌面宠物改进**（随本分支一并合入）：窗口点击穿透与内容贴合、玻璃质感边框、托盘设置入口、气泡尾巴一致性、宠物窗口保持屏幕内、单实例运行限制。

### 配置兼容性

- 无配置结构变更，既有配置继续原样生效。
- 新增的 DeepSeek Harness hooks 配置位于 `~/.dsh/familiar-hooks.json`（独立于各 agent 的既有配置文件）；若使用 DSH 桥接，需在 DSH 侧 `cordis.patch.yml` 的 `dsh-hooks-claude-code.configPath` 指向该文件。

### 隐私

本版本没有新增遥测、远程数据上报或外部服务。所有数据继续仅在本机采集、处理和显示。

### 平台与制品

- 本次 Release 计划提供以下安装包（draft 阶段，构建完成后上传）：
  - macOS Apple Silicon（arm64）DMG。
  - macOS Intel（x64）DMG。
  - Windows x86_64 NSIS 安装包。
  - Linux x86_64 deb 与 AppImage。
- 每个平台制品对应的 SHA-256 校验和见 Release 附件的 `SHA256SUMS`。
- macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。首次启动时 Gatekeeper 可能要求用户手动允许。
- Windows 安装包未做代码签名，SmartScreen 可能要求用户手动确认首次安装。
- Linux 安装包未经分发渠道签名。

### 性能数据

本轮为 hooks 集成与桌面窗口改进，无运行时性能变化。

## English

### Highlights

- **DeepSeek Harness (DSH) hooks integration**: a new `AgentSource::DeepSeekHarness` event source and a `DeepSeekHarnessHook` management module. Familiar now recognizes activity coming from DeepSeek Harness (file reads/writes, command runs, searches, subagents, etc.) and shows it with a dedicated **DSH** badge in the desktop pet and settings panel, distinct from Claude Code / Codex / Qoder / Antigravity.
  - A standalone hooks config file (`~/.dsh/familiar-hooks.json`) with inject / preview / uninstall support in the settings panel; commands carry the `--source deepseek-harness` marker.
  - Only the 7 events the DSH `dsh-hooks-claude-code` bridge actually supports are injected (`SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `Stop`, `SubagentStart`, `SubagentStop`), avoiding dead configuration.
- **Windows hook crash fixes**: when the DSH bridge runs hook commands through PowerShell on Windows, commands now use bare unquoted paths (PowerShell 5.1 cannot parse a quoted-path-plus-args call); `bin_path` prefers the release CLI in dev builds (the debug binary depends on the MSVC debug runtime, which can fail to initialize under GUI-hosted spawns).
- **Backup scan scope extended**: the hooks backup cleanup scan now includes `~/.dsh`.
- **Desktop pet improvements** (merged from this branch): click-through and content-hugging window with a glass frame, tray settings entry, consistent bubble tail, keep-on-screen restoration, and single-instance enforcement.

### Configuration compatibility

- No configuration schema changes; existing settings continue to work unchanged.
- The new DeepSeek Harness hooks config lives at `~/.dsh/familiar-hooks.json` (separate from each agent's existing config file); when using the DSH bridge, point `dsh-hooks-claude-code.configPath` in DSH's `cordis.patch.yml` at that file.

### Privacy

This release adds no telemetry, remote reporting, or external services. All data continues to be collected, processed, and displayed locally only.

### Platforms and artifacts

- This Release plans to include the following installers (draft stage; will be uploaded once built):
  - macOS DMG for Apple Silicon (arm64).
  - macOS DMG for Intel (x64).
  - Windows x86_64 NSIS installer.
  - Linux x86_64 deb and AppImage.
- SHA-256 checksums for each platform artifact are available in the `SHA256SUMS` release asset.
- The macOS application is ad-hoc signed and is not signed with an Apple Developer ID or notarized. Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- The Linux packages are not signed by a distribution channel.

### Performance data

This round is a hooks-integration and desktop-window improvement; no runtime performance changes were introduced.
