# Familiar v2.2.2

[中文](#中文) | [English](#english)

## 中文

### 主要功能与修复

- 修复 Windows 边缘吸附失效：低级鼠标钩子现在通过 `GetAsyncKeyState(VK_LBUTTON)` 判断真实左键状态，不再误把回调消息标识当作 `MK_LBUTTON` 按键位。
- 修复桌宠吸附到屏幕边缘后无法拖出的问题；拖拽逃逸状态会在新一轮拖拽开始时正确重置。
- 修复 Windows 平台悬停检测在鼠标穿透开启时不可靠的问题，继续使用事件驱动的低级鼠标钩子处理桌宠悬停状态。

### 兼容性与配置迁移

- 本版本不新增或修改用户配置字段，无需手动迁移配置。
- 现有桌宠悬停隐藏、悬停透明度和边缘吸附设置保持兼容。
- Windows x86_64 用户可直接覆盖安装；其他平台行为保持不变。

### 隐私影响

- 不新增遥测、网络上报或数据采集。
- Windows 鼠标钩子仅在本地处理鼠标位置和按键状态，用于桌宠悬停与拖拽交互，不记录或发送用户输入内容。

### 支持的平台与架构

- macOS Apple Silicon（arm64）与 Intel（x86_64）桌面包。
- Linux x86_64 deb 与 AppImage；桌面运行需要发行版提供 Tauri/WebKitGTK 依赖。
- Windows x86_64 NSIS 安装包；本版本重点修复 Windows 桌宠悬停与边缘吸附交互。
- `familiar-cli serve` 可在上述平台运行。

### 签名与公证状态

- macOS 使用 CI 配置的 ad-hoc 签名标识，不提供 Apple Developer ID 签名或公证；Gatekeeper 可能要求首次手动允许。
- Windows 安装包未配置代码签名；SmartScreen 可能要求首次安装手动确认。
- Linux deb/AppImage 未由发行版渠道签名。

### 性能数据

本版本未建立新的可复现端到端性能基线，不宣称量化性能变化。Windows 悬停与拖拽检测仍采用事件驱动处理，不引入轮询。

## English

### Major features and fixes

- Fixed Windows edge snapping being disabled: the low-level mouse hook now reads the actual left-button state with `GetAsyncKeyState(VK_LBUTTON)` instead of interpreting the callback message identifier as an `MK_LBUTTON` bitmask.
- Fixed the desktop pet becoming difficult to drag away after snapping to a screen edge; the drag-escape state is now reset correctly when a new drag begins.
- Fixed unreliable Windows hover detection while click-through is enabled; the event-driven low-level mouse hook continues to handle the pet hover state.

### Compatibility and configuration migration

- No user configuration fields are added or changed; no manual migration is required.
- Existing desktop-pet hover-hide, hover-opacity, and edge-snapping settings remain compatible.
- Windows x86_64 users can install this version over the existing installation; behavior on other platforms is unchanged.

### Privacy impact

- No telemetry, network reporting, or data collection is added.
- The Windows mouse hook processes cursor position and button state locally for desktop-pet hover and drag interaction; it does not record or transmit user input content.

### Supported platforms and architectures

- macOS desktop bundles for Apple Silicon (arm64) and Intel (x86_64).
- Linux x86_64 deb and AppImage packages; the desktop requires the distribution's Tauri/WebKitGTK dependencies.
- Windows x86_64 NSIS installer; this release primarily fixes Windows desktop-pet hover and edge-snapping interaction.
- `familiar-cli serve` can run on the platforms above.

### Signing and notarization status

- macOS uses the ad-hoc signing identity configured in CI and is not signed with an Apple Developer ID or notarized; Gatekeeper may require manual approval on first launch.
- The Windows installer is not code-signed; SmartScreen may require manual confirmation on first install.
- Linux deb/AppImage artifacts are not signed by a distribution channel.

### Performance data

No new reproducible end-to-end performance baseline was established for this release, and no quantified performance change is claimed. Windows hover and drag detection remain event-driven without introducing polling.
