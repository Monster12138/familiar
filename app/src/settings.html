自定义各 Agent 事件对应的宠物状态，保存后立即生效。未设置的事件沿用内置行为；会话终态清理只对「完成」状态生效。

通用配置

应用语言

开机自启
打开系统的登录启动项设置，将 Familiar 设为开机自启
API 端口
外部服务访问 Familiar HTTP API 的本地端口
Unix Domain Socket 路径
用于与本地原生 Agent 工具 (如 Antigravity, Claude Code) 进行极速通信的 UDS 文件路径。
通常无需修改，保持默认即可。
备用 TCP 端口
当操作系统不支持 UDS 时（如 Windows），使用的备用 TCP 通信端口
